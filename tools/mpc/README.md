# Part1 固定路线 MPC（规划中）

目标：改善 Part1 自动路线里"模型衔接"的段间过渡（对线、落位、转向、上下障碍前后的速度规划），
**不替换**现有 RL 过障策略。

## 分层

```
part1_auto_route (waypoints / 段状态机)
        │  reference pose / segment
        ▼
   路径跟踪 MPC（SE(2) 或差速/滑移模型，预测时域 1-2 s）
        │  (vx, wz)   （可选: vy 与小轮速偏置）
        ▼
   现有 RL 速度策略（vt_pose / vt_flat / row2p ...）
        │
        ▼
       sim
```

- 状态反馈允许使用世界位姿/速度真值（Part1 规则允许，只能用于生成指令，不进网络）。
- 输出只到速度层；不直接写关节/轮速（整机 MPC 另行研究）。
- Part2 规则仅允许 RL，MPC 不进 Part2 正式计分环；如使用只作为训练期 teacher/数据分析。

## 里程碑

1. 基线：pure-pursuit / Stanley 与现有 P 控制器同路线对比（航向/位姿误差、衔接时间、成功率）。
2. 速度层 SE(2) MPC：参考路径 + 速度/加速度约束，替换 `part1_auto_route` 的转向段。
3. 预测式落位：把下一段入口位姿作为终端代价，减少"到了再对线"的停顿。
4. （可选）轮足模型 MPPI：仅在难以落位的台面/桥头做局部对比。

## 评价口径

- 与判分解耦：MPC 只影响 `part1_auto_route` 的段间过渡；过障成功率仍由 `eval/` 判分。
- 同一策略、同一路线、同一 seed 下 A/B；记录航向误差、横向误差、段耗时、全路线结果。
