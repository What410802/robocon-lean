控制机制
小幅平滑转向会落入静摩擦死区 改用短时差速脉冲 → 制动 → 复核 停稳观察0.3秒；偏角<1°再前进
主动纠偏与验收记录分别解释
v102 / v103：过杆误差1.28° / 1.12° v104：降姿后已对准，主要执行复核 过杆误差0.69°，采样无杆柱接触
轮锁定是有限力矩的伺服目标
捕获切换时的非回绕轮角；q_target固定、dq_target=0，kp=80 / kd=3。 力矩限幅时降低增益，不移动锁定目标；负载下实际轮角允许弹性误差。 v104上台后记录的四轮目标角在停稳期间均保持不变。
