## 2. Part 1 障碍赛（900 分）

### 2.1 官方成功定义（官方 25th V1.0 表 2）

| 障碍 | 成功定义 | 失败条件 |
|---|---|---|
| 直角绕杆 slalom | 从任一圆形必达区出发，S 形绕过每根竖杆，经拐角必达区到另一侧圆形必达区 | 漏杆/乱序/离开场地 |
| 砂砾碎木坑 gravel_pit | 从 1 m 短边进入或离开；跨越过程中 1/2 以上足端触地则失败 | 2+ 足触地、长边出入 |
| 高墙 high_wall | 从上方跃过或攀爬通过 | 侧面绕行/未越过 |
| 限高杆 height_bar | 任何运动姿态从下方穿过，横杆不掉落 | 横杆掉落 |
| T 字台阶 t_stairs | 从任一方向迈上台阶，通过另一个台阶回到地面；每级顶面至少接触一次 | 2+ 足触地、漏级 |
| 斜坡 slope | 两侧斜坡上沿 3 m 长边方向累计行走 ≥1 m；1/2 以上足触地须重新越障 | 2+ 足触地、距离不足 |
| 木桥 A/B bridge | 从一侧平台经桥面到另一侧平台；上下平台方式不限 | 掉桥、同侧进出、2+ 触地 |

官方表 3 得分（遥控口径；本仓库 Part1 全程手动或自动均按遥控分，自动无额外分）：

- 每障碍 100 分；T 台阶上/下各 50（只完成一侧 50）；
- 8 障碍全过并回到启动区额外 +100；跳过障碍该障碍 0 分且不触发回程奖励。

### 2.2 本仓库实现约定（非官方原文）

- 砂砾坑要求进入和离开都走不同的合法短边（官方为“或”）。
- 木桥要求入口/出口侧相对、桥面接触 ≥3 帧、两侧平台均有接触证据。
- 高墙要求 4 个支撑点全部在墙 x 跨度内跨越墙平面。
- 限高杆要求从门洞 x 范围穿过；高度用 base-z 代理（mjdata 几何判定留作后续）。
- T 台阶：异臂上下 100；同臂上下 50；单侧 50；漏级失败。
- 恢复姿态容差 0.30 m / 0.52 rad 属于测量余量。

## 3. Part 2 越障能力测试（1300 分）

### 3.1 任务规则要点

- 六类障碍，每种至多 4 次挑战，只记录能通过的最高难度；不计时。
- 仅允许强化学习策略，不能写固定动作；可以自定义地图，但障碍必须保持官方同类。
- 传感器/真值限制同 Part1；电机瞬时力矩 hip/thigh ≤25 N·m，calf ≤60 N·m。
- “上述所有障碍均需要能够反复稳定越过”（规则备注；目前作为质量指标，不是计分条件）。

### 3.2 官方评分曲线（`rules.py` 同源）

| 类别 | 档位 → 分数 | 说明 |
|---|---|---|
| high_platform | 10/20/30/40 cm → 10/50/100/200 | 40 cm 满分；10 cm 以下不得分 |
| stairs | 10/15/20/30 cm → 10/50/100/200 | 6 级×0.30 m（30 cm 档） |
| slope | 20/30/35/45° → 10/50/100/200 | 45° 满分；20° 以下 0 |
| high_wall | 10/20/30/40 cm → 0/50/100/200 | PDF “10 cm 以下不得分”，本实现取 10 cm = 0 |
| trench | 10/30 cm → 0/300 | 中间按比例；10 cm 以下不得分 |
| plum | 通过 → 200 | PDF 6 桩图，见 §3.3 |

档位之间按线性比例取分、结果向下取整（比官方“按比例”略严）。

### 3.3 梅花桩几何（按 PDF 图重建）

规则 PDF 说明提供地图的参数有误，按图重建：

- **无坡道**：入口/出口各一块 0.8×0.8×0.2 m 平台；
- 中间 **6 根** 0.2×0.2×0.2 m 方桩，**两排交错**：
  第一排 (x,y)=(2.8,0.2)/(3.4,0.2)/(4.0,0.2)，第二排 (3.1,-0.2)/(3.7,-0.2)/(4.3,-0.2)；
- 同排桩边距 0.4 m；两排边距 0.2 m；首桩距平台 0.1 / 0.4 m（两排）；
- 平台外沿总长 3.5 m，中心对称；从出口平台远边下 0.2 m 台阶到地面。

几何单一来源：`terrain/gen_plum.py`（生成 `terrain/plum/plum_spec.json`、
`terrain/official/part2_terrain_spec.json` 的 plum 段、判分 manifest 与训练地形）。

### 3.4 本仓库实现约定（非官方原文）

- 高台按官方口径：四轮上到台顶并 hold 即成功，**不要求从远侧下去**。
- 楼梯/斜坡/沟壑/高墙/梅花桩：到达目标支撑面 → hold → 下到另一侧正常地面。
  这是把官方“越过/通过”变成可测终端态的操作化，官方原文没有这么细。
- 车道 |y|≤0.7 不是官方失败项，本实现也不再据此判失败；只在部分证据检查中用于确认
  机器人确实在障碍上（防绕行）。
- 跌倒阈值 75° / base z<0.15 m、hold 0.2 s（+0.1 s 稳定余量）、高墙 y 跨度、沟壑轮底下沉
  阈值、梅花桩轮底 ≥0.05 m 均为实现选择，不是官方原文。
- 关卡超时 120 s 只是安全帽（官方不计时）。

## 4. 机器人 / 传感器 / 契约

- blackW：16 DoF（4×(hip, thigh, calf, wheel)）；obs 57×6 history；action 16；
  50 Hz 推理、200 Hz 控制、2 ms 物理；kp=50、kd=1.2（关节），轮子 kp=0；力矩上限见 §3.1。
