## 2. Part 1 障碍赛（900 分）

### 2.1 官方成功定义（官方 25th V1.0 表 2）

| 障碍 | 成功定义 | 失败条件 |
|---|---|---|
| 直角绕杆 slalom | 从任一圆形必达区出发，S 形绕过每根竖杆，经拐角必达区到另一侧圆形必达区 | 漏杆/乱序/离开场地 |
| 砂砾碎木坑 gravel_pit | 从 1 m 短边**进入或离开**；跨越过程中 1/2 以上足端触地则失败，须重新越障 | 2+ 足触地、长边出入 |
| 高墙 high_wall | 从上方跃过或攀爬通过（1.0×0.3×0.05 m） | 侧面绕行/未越过 |
| 限高杆 height_bar | 任何运动姿态从下方穿过，横杆不掉落（杆底 0.30 m） | 横杆掉落 |
| T 字台阶 t_stairs | 从任一方向迈上台阶，通过另一个台阶回到地面；每级顶面至少与足底接触一次；1/2 以上足触地失败 | 2+ 足触地、漏级 |
| 斜坡 slope | 两侧斜坡上沿 3 m 长边方向行走距离合计 ≥1 m；1/2 以上足触地须重新越障（10°×3 m） | 2+ 足触地、距离不足 |
| 木桥 A/B bridge | 从一侧平台经桥面到另一侧平台；上下平台方式不限；1/2 以上足触地失败 | 2+ 足触地、未到对侧 |

官方表 3 得分（遥控口径；本队 Part1 全程手动或自动均按遥控分，自动无额外分）：

- 每障碍 100 分；**T 台阶上/下各 50**（只完成一侧 50）；砂砾坑必须完整通过；
- 8 障碍全过并回到启动区额外 **+100**；跳过障碍该障碍 0 分且不触发回程奖励。

### 2.2 队内更严约定（标注为"合理性子约束"，非官方原文）

- 砂砾坑要求**进入和离开都走短边**（官方"或"→队内"且"）。
- 木桥要求入口侧与出口侧相对，且桥面接触 ≥3 帧、两侧平台均有接触证据。
- 高墙要求 4 个支撑点全部在墙 x 跨度内跨越墙平面。
- 限高杆要求从门洞 x 范围穿过；高度用 base z 代理（后续改 mjdata 几何判定）。
- T 台阶：上一条臂 + 下**另外两条臂之一** = 100；同臂上下 = 50；单侧 = 50；漏级 = 失败。
- 恢复容差 0.30 m / 0.52 rad（测量余量；队内目标是全程不摔）。

## 3. Part 2 越障能力测试（1300 分）

### 3.1 赛题规则要点

- 六类障碍、每种可多次挑战；**每障碍至多 4 次挑战机会**，**每种障碍只记录能通过的最高难度**。
- **不计时**（只按越障得分）。
- **仅允许强化学习策略，不能写入固定动作**。
- 传感器/真值限制同 Part1：IMU、编码器、相机/雷达；禁止 body_lin_vel、heightmap、foot force、
  foot height、body height；世界位姿真值只可用于生成指令，不得进网络。
- 电机瞬时力矩：hip/thigh ≤25 N·m，calf ≤60 N·m。
- "上述所有障碍均需要能够反复稳定越过"（规则备注；目前作为质量指标，不是计分条件）。
- 可以自定义地图，但障碍必须保持同一种类。

### 3.2 官方评分曲线（`rules.py` 同源）

| 类别 | 档位 → 分数 | 说明 |
|---|---|---|
| high_platform | 10/20/30/40 cm → 10/50/100/200 | 40 cm 满分；10 cm 以下不得分 |
| stairs | 10/15/20/30 cm → 10/50/100/200 | 30 cm 为踢面高（6 级×0.30 m） |
| slope | 20/30/35/45° → 10/50/100/200 | 45° 满分；20° 以下 0 |
| high_wall | 10/20/30/40 cm → 0/50/100/200 | 10 cm 不得分 |
| trench | 10/30 cm → 0/300 | 中间按比例；10 cm 以下不得分 |
| plum | 通过 → 200 | 本队 3 桩版本，见下 |

档位之间按线性比例取分、结果向下取整（比规则"按比例"略严）。

### 3.3 梅花桩（队内确认的实际参数）

规则 PDF 说明提供地图的梅花桩参数有误；队内实际布置（已由负责人确认）：

- **无斜坡**：入口/出口各一块 **0.8×0.8×0.2 m** 平台，机器人直接上/下 0.2 m 台阶；
- 中间 **3 根** 0.2×0.2×0.2 m 方桩，沿行进方向**单排**，桩心距 **0.6 m**；
- 平台边沿与首/末桩间隙 **0.1 m**；桩区中线与通道中线重合；
- 通过 = 跨过 3 桩不落地、经出口平台下到正常地面。

场景与 judge 参数由 `terrain/gen_plum.py` 生成，`eval/SPEC.md` 记录判分口径。

### 3.4 队内更严约定

- 六类都要求"上去 → 稳定 hold → 从另一侧下来"（队内原因：实际要一次启动走完所有障碍）。
- 关卡超时仅 120 s 安全帽（官方不计时）。
- 通道 |y| ≤ 0.7 m + 0.02 m 容差、0.6 s 宽限；墙体 y-span；fall 阈值 75°。
  这些是**人为合理性约束**，已在 SPEC 与代码注释中与官方规则分开。
- 沟壑轮底下沉阈值（平台顶下 0.103 m）比官方"不触地"更严；梅花桩轮底 <0.05 m 判落地。
